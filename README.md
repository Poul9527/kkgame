# KK Arcade Hub (极客游戏大厅) 🎮

现代化、全功能、极具视觉冲击力的 Vue 3 街机游戏大厅。开箱即玩，纯前端零外部依赖，集成 Web Audio API 动态合成 8-bit 原生音效。

![KK Arcade](public/favicon.svg)

---

## ✨ 核心特性

- 🕹️ **内置 7 款高品质经典游戏**：
  - ♠️ **德州扑克 (Texas Hold'em Poker)**：国际顶级智慧扑克博弈！7选5最优牌型组合、完整四轮下注（翻牌前、翻牌、转牌、河牌）、过牌、跟注、加注与孤注一掷 All-In、庄家位与盲注轮转、三位竞技风格 AI。
  - 🎴 **欢乐炸金花 (Golden Flower Poker)**：经典四人扑克博弈对决！闷牌看牌、底池加注偷鸡、1v1 绝杀比牌对决、权威牌型（豹子、顺金、金花、顺子、对子、特殊235克制豹子）与三位鲜明性格电脑 AI。
  - ♟️ **极智五子棋 (Gomoku Pro)**：内置高强度启发式博弈 AI（初级/进阶/大师难度），支持人机对战与双人同屏对弈，支持悔棋、落子动画与胜负判定。
  - 🐍 **霓虹贪吃蛇 (Neon Snake)**：街机霓虹画风，多种随机道具掉落（苹果、黄金币、冰晶减速、高分爱心），支持键盘 WASD 与触屏虚拟十字摇杆。
  - 🔢 **2048 极速版 (2048 Neon Blast)**：丝滑方块滑动合并动画，支持撤回上一步，自动检测 2048 胜利与死局。
  - 🚀 **星际雷霆战机 (Galaxy Striker)**：60FPS Canvas 弹幕射击引擎，多波次敌机编队、子弹升级系统（双发火炮、散射激光）、护盾道具、Boss 战与粒子爆炸特效。
  - 💣 **扫雷先锋 (Minesweeper Elite)**：首击必空安全机制，连环自动扩散展开，初级/中级/高级三种规格雷区，插旗模式与计时推演。
- 🎵 **Web Audio 原生音效合成引擎**：零外部音频文件加载，实时代码合成 8-bit 街机按键、射击、爆炸、金币、升级、胜利及复古 BGM 旋律。
- 🪙 **完善的经济与成就生态**：
  - **金币体系**：游戏结算、打破纪录或每日签到奖励金币。
  - **成就荣誉墙**：8 项核心成就，解锁即享金币奖励与彩带礼炮。
  - **名人堂排行榜**：本地高分与街机排行榜，实时刷新名次。
  - **主题与头像商城**：金币兑换 4 套大厅配色风格（赛博霓虹、矩阵代码、深邃暗夜、复古街机）及专属玩家头像。
- 📱 **全平台自适应**：全面适配桌面端与移动端触屏交互。

## 🚀 快速启动

本项目基于 Node.js 与 Vite 构建，只需以下命令：

```bash
# 1. 安装依赖
npm install

# 2. 启动开发服务器
npm run dev

# 3. 生产打包
npm run build
```

启动后在浏览器打开：`http://localhost:5173` 即可立即进入游戏大厅。

## 🛠️ 技术栈

- **框架**: Vue 3 (`<script setup>`, Composition API)
- **路由**: Vue Router 4
- **状态管理**: Pinia (配合 LocalStorage 持久化存储)
- **构建工具**: Vite 6 + TypeScript
- **图标库**: Lucide-Vue-Next
- **特效库**: Canvas-Confetti
- **样式体系**: 现代赛博朋克 / 玻璃拟态 (Glassmorphism & Neon Glow)

---

## 🔌 后端扩展支持 (Node / Python / Java)

项目目前已实现前端完整游戏闭环与本地持久化。如需接入联机对战、全局排行榜或账户系统，可随时接入后端服务：
- **Node.js (Express / Fastify / Socket.IO)**: 适合做多人 WebSocket 实时对战（如五子棋联机对局）。
- **Python (FastAPI / Django)**: 适合实现 AI 强化学习算法或云端分析。
- **Java (Spring Boot)**: 适合构建大型用户微服务与支付体系。
